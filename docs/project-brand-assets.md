# Project tile assets

The Projects page stores these marks locally so the cards do not depend on third-party image servers at runtime. Sources were checked on September 25, 2026.

| File | Official source |
| --- | --- |
| `personify.svg` | [Personify site header](https://www.personifyhq.com/) inline SVG wordmark |
| `codapet.svg` | [CodaPet wordmark](https://www.codapet.com/images/codapet-new-logo-wordmark.svg) |
| `route.png` | [Route site](https://www.getroute.com/) header logo |
| `exchange.png` | [Route Exchange banner](https://exchange.getroute.com/images/exchange-banner-lg.png) |
| `alogent.png` | [Alogent NXT demo](https://nxt-scout.netlify.app/sign-in) logo, shared by the Design Language and NXT tiles |
| `scroodles.webp` | [Scroodles App Store listing](https://apps.apple.com/us/app/scroodles/id912236766) app icon |
| `tiffinity-wordmark.png` | Existing Tiffinity wordmark from `tiffinity-mvp-2026/public/images/tiffinity-logo.png`, reused October 2, 2026; project links to [Tiffinity](https://tiffinity.food/) |

The Personify SVG sets its official dark navy as an explicit color because its source relied on a CSS `currentColor` value. The Design Language tile uses a blue tint and the NXT tile a green tint, reflecting the palette shown in the [Design Library](https://alogent-design-language.netlify.app/).
